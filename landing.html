Installation

Ready in 30 seconds.

Load the extension as an unpacked Chrome extension. No build step, no dependencies, no account required.

Open chrome://extensions
  1. 1Open chrome://extensions in your browser.
  2. 2Enable Developer mode in the top-right corner.
  3. 3Click Load unpacked and select this project folder.
  4. 4Pin the extension and click it on any page you want to scan.
